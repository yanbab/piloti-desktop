Technology

Web meets Wayland.

A web UI on top. A native session underneath.

Web

  • React, Tailwind and Adwaita primitives.
  • Plugins in JS and CSS. Hot reload.
  • Web apps as first-class windows.
  • Runs in any browser for demos.
+

Wayland

  • Native app windows. CSD and SSD.
  • X11 apps with xwayland-satellite.
  • Login with greetd.
  • Powered by Domicile.

Get started

Install on Debian or Ubuntu.

From a .deb or from source. A new session at login.

1

Domicile Required

A Wayland compositor built on Chromium. The shell is a web page. Apps are real native windows. Fast, GPU-accelerated, and scriptable.

Get Domicile →

2

Piloti Desktop

Install the .deb, or build from source. Pick Piloti at login.

Download from Releases →

3

X11 apps Optional

Need X Window apps? Install xwayland-satellite.

xwayland-satellite on GitHub →

Terminal
# Option A — install the .deb from Releases
sudo apt install ./piloti-desktop_*_all.deb

# Option B — build from source
git clone https://github.com/yanbab/piloti-desktop
cd piloti-desktop
npm install
npm run build:deb
sudo apt install ./dist/piloti-desktop_*_all.deb

See it move.

No install needed.
