Designed for Real Wayland Workflows

Lightweight React & Tailwind shell with native Linux system integrations.

W

Native Wayland & CSD

Embeds client windows via <app>, syncs xdg_toplevel tiled states to strip redundant GTK shadows, remembers bounds per app, and snaps on screen edges.

X

XDG Apps & Icon Themes

Full FreeDesktop Desktop Entry & Icon Theme Spec parser loads installed .desktop apps and real SVG/PNG icons from Adwaita, hicolor, and Flatpak exports.

G

GNOME Stack Bridge

Two-way GSettings sync, gnome-control-center panel launching, PipeWire volume/sinks (wpctl / pactl), NetworkManager (nmcli), and UPower.

A

Cupertino & Adwaita Themes

Switch instantaneously between translucent Liquid Glass and official GNOME 47 / Libadwaita 1.6 surfaces, radii, and accent colors.

P

Live Previews & Portals

Alt+Tab captures live PNG frames, LockScreen authenticates via PAM, and PortalDialogs handles screenshots, screen casts, and color picking.

C

Zero-Offset DRM Cursors

Anchors custom SVG hardware cursor hotspots at (0, 0) for pixel-accurate clicks under Ozone/DRM and VMware vmwgfx.

Quick Start

Run in a macOS/Linux browser harness or launch natively inside Domicile.

Terminal — Local Dev & Linux Launch 
# 1. Install dependencies & launch browser harness
bun install
bun run dev

# 2. Run directly on Linux with Domicile
domicile ./desktop.tsx

# 3. Or build standalone shell bundle & run tests
bun test && bun run typecheck && bun run build
domicile ./dist/shell.js
