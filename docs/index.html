Features

Everything built into the Piloti desktop shell.

Wayland Windows & CSD

Native <app> surfaces, edge snapping, spatial per-app bounds, and live Alt+Tab / Overview workspace previews.

Menu Bar, Launcher & Control Panel

Global app menus, DBusMenu System Tray, instant Launcher search & calculator, quick settings, and notification history.

Animated Icons, Dock & Spatial Desktop

Accent-tinted Papirus & Lottie animated folders, files, and Trash with a magnifying Dock and spatial ~/Desktop grid.

Dynamic Wallpapers & Plugins

Adaptive light/dark wallpapers, live CSS & HTML animated backgrounds, and hot-reloadable JS/CSS shell and GTK plugins.

GNOME & FreeDesktop Integration

Two-way GSettings sync, PipeWire, NetworkManager, UPower, Flatpak, XDG Portals, Trash, Recents (XBEL), and MimeApps.

Built-in Apps, Greeter & Console

Folders, Desktop Shell, Notepad, Calculator, Image Viewer, Applications Store, GDM Login Screen, and Desktop Console.

Quick Start

Run in a browser harness locally or launch natively inside Domicile.

Terminal — Local Dev & Linux Launch 
# 1. Install dependencies & launch browser harness
bun install
bun run dev

# 2. Run directly on Linux with Domicile
domicile ./desktop.tsx

# 3. Or build standalone shell bundle & run tests
bun test && bun run typecheck && bun run build
domicile ./dist/shell.js
