Getting Started

Welcome to Piloti Desktop

A quick guide to the Menu bar, Dock, Desktop icons, and essential shortcuts.

Desktop Basics

Menu Bar

Access app menus on the left, click the center pill to toggle Overview, and open Launcher or Control panel & notifications on the right.

Dock

Launch pinned apps, switch running windows, or open Trash. Drag pinned tiles to reorder them, or right-click for window actions.

Desktop Icons

Single-click items to open, drag to place anywhere on the grid, drag across empty space for rubber-band selection, or navigate with Arrow keys.

Launcher & Overview

Press Alt + Space to search apps, folders, settings, or URLs. Use Overview to spread windows and drag them across workspaces.

Control Panel & Settings

Adjust Wi-Fi, Bluetooth, Volume, Brightness, Do Not Disturb, and notification history in Control panel, or customize themes and wallpapers in Desktop Settings.

Window Snapping

Drag windows to screen edges or hold Alt while dragging anywhere inside a window to move it effortlessly.

Keyboard Shortcuts

Open Launcher (search apps, folders, actions, URLs) Alt + Space
Switch open windows with live previews Alt + Tab
Toggle Overview (workspaces & window spread) Meta + ↑ / F3
Toggle Control panel & Notifications Alt + N
Take interactive screenshot Print
Launch Terminal Meta + Return
Open Desktop Settings Alt + ,
Tile focused window left / right half Alt + [ / Alt + ]
Maximize / restore focused window Alt + F
Minimize focused window Alt + M
Close focused window Alt + W
