I'm making my own desktop with Domicile, a Linux desktop whose shell is a web page. Read https://domicile-desktop.com/llms.txt first.

I want to use https://www.cupertino-ui.com/.
Design takes inspiration from gnome and macOS, but is not a clone.

The shell consists of a top menubar, where on the left there are menu items for the current app, and on the right there are system status indicators. 

Dock on the bottom, with icons of running apps, and a stack for favorites on the right. Design similar to macos dock.

Windows are floating on top of the shell.

Alt tab implementation similar to windows.

Command pallette to search and lauch apps, switch windows, and perform system actions. Alt+Space to open.

Panel on the menubar right side for notifications and quick settings (clock, volume, brightness, etc.).

Settings application for managing system settings. (Apparence, dock, background, network, sound, etc.)


Responsive design. Fluid, Simple.

I should be able to develop / run under browser /macos, with sample apps. I'll test with vmware (debian).
